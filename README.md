# Task Management API

A RESTful API built with ASP.NET Core 8 following Clean Architecture principles.

## Features

- JWT Authentication
- User Management
- Task Management
- Role-based Authorization
- Logging
- API Documentation

## Technologies

- ASP.NET Core 8
- Entity Framework Core
- SQL Server
- JWT
- FluentValidation
- AutoMapper
- Serilog

## Architecture

- API
- Application
- Domain
- Infrastructure

## Setup

1. Clone repository
2. Update connection string
3. Run migrations
4. Run project
